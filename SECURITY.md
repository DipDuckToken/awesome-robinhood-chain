# Security policy

## Reporting a vulnerability

Please report privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository, or email
hi@heyresearch.xyz with a subject starting "Security". Do not open a public issue. We aim to acknowledge within 3
working days. There is no bug bounty for this repository.

A listed link that points somewhere harmful (a phishing page, a look-alike domain, a contract that is not the
project's) is a security issue: report it the same way.

## Scope

This repository is a generated list: `scripts/` regenerates `README.md` from HEY Research Lab's open dataset once a
week. The links in it are data and are never fetched by anything here.

A security issue in a listed project belongs to that project: use its own security policy, or its repository's
private vulnerability reporting.
